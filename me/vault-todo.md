## Current Phase: 0 — Fresh Vault

This is a freshly-cloned vault template. The focus of Phase 0 is populating the personal layer through guided setup (see `SETUP.md`).

### Phase 0 tasks

- [ ] Complete guided setup — run `help me set this up` at vault root
- [ ] Populate `me/profile.md`
- [ ] Populate `me/voice.md` (and sync to `skills/library/voice.md`)
- [ ] Seed `me/doctrine.md` with 2–3 doctrines
- [ ] Create first project context in `/projects/`
- [ ] (Optional) Gobble 3–5 active reading sources
- [ ] (Optional) Distill past conversations from Claude.ai / ChatGPT

### Once Phase 0 is complete

Move to **Phase 1 — Active Use**:

- Daily loop: capture ideas, gobble interesting sources
- Weekly review: 15 minutes, Fridays or Sundays
- Add new project contexts as projects start
- Add new doctrines as patterns crystallize
- Promote inbox skills to library once they've earned a real-usage gotcha
