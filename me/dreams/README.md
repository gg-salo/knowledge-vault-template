# Dreams Staging

Dream Layer outputs land here. These are NOT vault writes — they are proposals from the [[dream]] workflow staged for review.

## What lives here

Each file is a candidate output from a `/dream` run:
- Cross-candidate synthesis on a batch of fresh gobbles
- Connection proposals between new material and existing vault
- Content angles awaiting curation

## How they exit

[[converge]] reads this directory as one of its primary sources during weekly synthesis. Dreams that connect to other vault elements get promoted into ranked opportunities. Dreams that sit alone get pruned during weekly review.

## What this is NOT

- Not a permanent storage location
- Not an idea inbox (that's `/me/ideas/_INBOX.md`)
- Not vault content (that's `/me/published/_INDEX.md` after shipping)

## Connected Files

- [[dream]] — workflow that produces dreams
- [[converge]] — workflow that curates dreams
- [[_RULES]] — vault constitution
