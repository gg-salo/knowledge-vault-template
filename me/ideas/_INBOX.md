## How to Add an Entry

Use `capture idea: [text]` in any Claude Code session at vault root. Claude will append a new numbered entry using this format:

```markdown
### [N]. [Short descriptive title]
- **Idea:** [The core thought — one or two sentences, no hedging]
- **Pattern:** [Abstract-level description — the underlying pattern, domain-agnostic]
- **Sparked by:** [What triggered this — a conversation, something read, a project observation, a date]
- **Connects to:** [[project-or-doctrine-or-reading-file]] [[another-one]]
- **Status:** raw | developing | ready-to-act | dismissed
- **Notes:** [Optional — anything that would help a future you understand this]
```

The **Pattern** line is the critical field. It's what makes the inbox searchable at the abstract level. With 50+ ideas, pattern-level grouping surfaces clusters invisible when reading sequentially.
